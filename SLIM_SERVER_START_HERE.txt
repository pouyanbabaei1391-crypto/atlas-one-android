ATLAS ONE — SLIM LOCAL GEMMA BUILD

This edition has one GitHub workflow: Build Atlas Android Slim APK.

BUILD
1. Run UPDATE_TO_GITHUB.bat.
2. Open GitHub Actions > Build Atlas Android Slim APK.
3. Select Run workflow.
4. Download Atlas-One-Android-Slim-Local-Gemma from Artifacts.

RUNTIME
- Voice questions use Gemma 3 4B locally on the phone.
- An already-installed Gemma model is retained when this APK updates the same app.
- If Gemma is absent, the local setup can download it; the APK stays Slim.
- No cloud model, API key, Gateway, or server URL is required.

IMPORTANT
Do not uninstall the previous app and do not clear its storage if you want to keep
the already-downloaded 2.5 GB model.

Local response speed depends on phone CPU/RAM, model warm-up, speech recognition,
answer length, and text-to-speech. A 4B model cannot be guaranteed to start
speaking in under one second on every Android device.
