ATLAS ONE - SLIM INSTALLER (UNDER 800 MB)
=========================================

WHAT THIS ADD-ON DOES
---------------------
It adds a second Android build route that excludes the 1,107,409,376-byte
Qwen3 weight file from the APK. The existing application architecture,
voice features, original bundled build, and Update to GitHub route are kept.

The slim APK downloads the exact same model during first-time setup:
  Qwen3-1.7B-Q4_K_M.gguf
  Expected size: 1,107,409,376 bytes
  SHA-256: ba491cf470c3cadc624e4c8d6c9a27c998809e8ba8eb938d1689ae87e024b6b7

This preserves model quality byte-for-byte. It reduces installer size, not
the final storage occupied by the installed model.

GITHUB
------
Use UPDATE_TO_GITHUB.bat exactly as before. Then open Actions and run the single
workflow named "Build Atlas Android Slim Qwen3 APK". It publishes:
  Atlas-One-Android-SLIM-QWEN3-APK

The workflow fails instead of publishing if the APK is over 800,000,000 bytes.

LOCAL WINDOWS BUILD
-------------------
Run:
  BUILD_LOCAL_GEMMA_SLIM_ANDROID.bat

The verified result is:
  dist\Atlas-One-Android.apk

WHY THIS DOES NOT USE 1-BIT QUANTIZATION
----------------------------------------
A 1-bit conversion changes model weights and can reduce quality. This route
uses Q4_K_M for a practical balance of mobile speed, size, and answer quality.
