ATLAS ONE - SLIM INSTALLER (UNDER 800 MB)
=========================================

WHAT THIS ADD-ON DOES
---------------------
It adds a second Android build route that excludes the 2,489,758,112-byte
Gemma weight file from the APK. The existing application, model identity,
voice features, original bundled build, and Update to GitHub route are kept.

The slim APK downloads the exact same model during first-time setup:
  google_gemma-3-4b-it-Q4_K_M.gguf
  Expected size: 2,489,758,112 bytes
  SHA-256: 4996030242583a40aa151ff93f49ed787ac8c25e4120c3ae4588b2e2a7d1ae94

This preserves model quality byte-for-byte. It reduces installer size, not
the final storage occupied by the installed model.

GITHUB
------
Use UPDATE_TO_GITHUB.bat exactly as before. A new workflow named
"Build Atlas Android Slim APK" runs automatically and publishes the artifact:
  Atlas-One-Android-SLIM-APK

The workflow fails instead of publishing if the APK is over 800,000,000 bytes.

LOCAL WINDOWS BUILD
-------------------
Run:
  BUILD_LOCAL_GEMMA_SLIM_ANDROID.bat

The verified result is:
  dist\Atlas-One-Android.apk

WHY THIS DOES NOT USE 1-BIT QUANTIZATION
----------------------------------------
A 1-bit conversion changes model weights and cannot honestly guarantee zero
quality loss. The slim route keeps the existing Q4_K_M model unchanged and
therefore preserves its coherence and output quality.
